## 前言 2026/4/13 
  
前言的内容不多，主要提及了LLM的发展史，是在PLM的基础上增加了参数量。本质功能是文本生成。但是在一些调用技巧的使用下比如context涌现了智能。Agent是LLM的调用程序，例举一个经典的应用场景，这个让我想到了22年ChatGPT刚火爆的时候，大家通过一系列的微调，做了猫娘版的GPT。这其实应该是最早期的agent，用户给agent发问：“今天是什么天气？”agent向LLM发问：“今天是什么天气？你可以通过联网查询，记得要使用前文提及的猫娘口吻回答我，比如每句话的结尾最后一个词换成喵。”LLM向agent回答：“今天是晴天喵，主人要注意防晒喵。”agent再把这段回复发给用户。自此，我们就建立了一个猫娘agent。当然，这个agent还可以集成很多其他功能，现在叫做skill，比如deepseek 的联网搜索这个选项，其实就是agent集成了一个RAG的skill。Skill本身是一个markdown文档和几个脚本程序，md里面包含了固定的提示词。调用LLM必定产生token的消耗，而agent和skill产生的消耗本质是它们调用了LLM产生的消耗。当然skill的出现是大量减少token消耗的关键，而且主要消耗在于理解用户的语义，而调用脚本几乎是免费的。

## Chapter 1 NLP 基础概念 2026/4/14

自然语言处理（Natural Language Processing，NLP）作为人工智能领域的一个重要分支，旨在使计算机能够理解和处理人类语言，实现人机之间的自然交流。在NLP的广阔研究领域中，有几个核心任务构成了NLP领域的基础，它们涵盖了从文本的基本处理到复杂的语义理解和生成的各个方面。  

### 中文分词（Chinese Word Segmentation, CWS）、
是 NLP 领域中的一个基础任务。在处理中文文本时，由于中文语言的特点，词与词之间没有像英文那样的明显分隔（如空格），所以无法直接通过空格来确定词的边界。子词切分（Subword Segmentation）是 NLP 领域中的一种常见的文本预处理技术，旨在将词汇进一步分解为更小的单位，即子词。子词切分特别适用于处理词汇稀疏问题，即当遇到罕见词或未见过的新词时，能够通过已知的子词单位来理解或生成这些词汇。子词切分在处理那些拼写复杂、合成词多的语言（如德语）或者在预训练语言模型（如BERT、GPT系列）中尤为重要。  
<mark>使用子词切分（假设BPE算法）：单词unhappiness被分割为：“un”、“happi”、“ness”</mark>

### 文本分类（Text Classification）
文本分类（Text Classification）是 NLP 领域的一项核心任务，涉及到将给定的文本自动分配到一个或多个预定义的类别中。这项技术广泛应用于各种场景，包括但不限于情感分析、垃圾邮件检测、新闻分类、主题识别等。文本分类的关键在于理解文本的含义和上下文，并基于此将文本映射到特定的类别。  
<mark>文本：“NBA季后赛将于下周开始，湖人和勇士将在首轮对决。”
类别：“体育”  
文本：“美国总统宣布将提高关税，引发国际贸易争端。”
类别：“政治”  
文本：“苹果公司发布了新款 Macbook，配备了最新的m3芯片。”
类别：“科技” </mark> 

### 实体识别（Named Entity Recognition, NER）
实体识别（Named Entity Recognition, NER），也称为命名实体识别，是 NLP 领域的一个关键任务，旨在自动识别文本中具有特定意义的实体，并将它们分类为预定义的类别，如人名、地点、组织、日期、时间等。实体识别任务对于信息提取、知识图谱构建、问答系统、内容推荐等应用很重要，它能够帮助系统理解文本中的关键元素及其属性。  
<mark>输入：李雷和韩梅梅是北京市海淀区的居民，他们计划在2024年4月7日去上海旅行。  
输出：[("李雷", "人名"), ("韩梅梅", "人名"), ("北京市海淀区", "地名"), ("2024年4月7日", "日期"), ("上海", "地名")]</mark>

### 文本摘要（Text Summarization）
文本摘要（Text Summarization）是 NLP 中的一个重要任务，目的是生成一段简洁准确的摘要，来概括原文的主要内容。根据生成方式的不同，文本摘要可以分为两大类：抽取式摘要（Extractive Summarization）和生成式摘要（Abstractive Summarization）。  

抽取式摘要：抽取式摘要通过直接从原文中选取关键句子或短语来组成摘要。优点是摘要中的信息完全来自原文，因此准确性较高。然而，由于仅仅是原文中句子的拼接，有时候生成的摘要可能不够流畅。  

生成式摘要：与抽取式摘要不同，生成式摘要不仅涉及选择文本片段，还需要对这些片段进行重新组织和改写，并生成新的内容。生成式摘要更具挑战性，因为它需要理解文本的深层含义，并能够以新的方式表达相同的信息。生成式摘要通常需要更复杂的模型，如基于注意力机制的序列到序列模型（Seq2Seq）。  

文本摘要对于LLM延长记忆有很大的作用，前段时间Claude的前端代码被开源，一些分析博主发现Claude在记忆方面做的很杰出的一个原因就是它对于每次的上下文都会生成一个摘要，除去教程中描述的抽取式摘要和生成式摘要关于流程度和准确性的差距，我认为它们还有一个重要的差距就是生成出摘要的文本长度，生成式摘要的长度显然远小于抽取式，并且可以根据用户的关注点利用注意力机制抛出不必要的消息，比如用户在做一个深度学习的项目，一般使用条件下，用户应该会经常发“帮我生成全部代码”，“帮我修改代码中的错误”，这时候LLM的记忆长度被剧烈消耗，但实际上这里面的东西对于LLM上下文理解都是没有用的，在这个例子中，一个需要保留的信息就是用户使用了什么模型，一旦用户提出“帮我把损失函数由MER更换为CCC”这种需求，大模型可以通过查看摘要中的索引，快速定位到最后完整的代码。当然代码这个例子已经不适用了，现在很多编程agent比如codex都可以直接在IDE里面调用实时地查看和修改代码。但对于其他领域的LLM，通过生成摘要来压缩上下文延长记忆是一个非常有效的手段。

### 机器翻译（Machine Translation, MT）
机器翻译（Machine Translation, MT）是 NLP 领域的一项核心任务，指使用计算机程序将一种自然语言（源语言）自动翻译成另一种自然语言（目标语言）的过程。  

机器翻译和最开始的直接依照词典对译的方式最显著的区别就是前者需要做到准确传达源语言文本的语义、风格和文化背景等。一个机器翻译比较好用的场所就是前文所提到的中文分词，一个方式就是将中文先翻译成英文，然后做分词再翻译回来。在翻译模型性能优越的情况下比研究如何做好中文分词更具有优势。而且显然的，机器翻译的数据集十分的广大，各种翻译家译的文学作品就是一个用不完的数据集，而在机器学习中数据集质量更高的项目往往取得进展是比较简单的，所以上述方式的可用性是比较好的。

### 自动问答系统（Automatic Question Answering, QA）
自动问答系统的构建涉及多个NLP子任务，如信息检索、文本理解、知识表示和推理等。  

在LLM突破性进展之前，这个任务的限制条件一直是如何理解文本，包括用户输入的需求和搜索到的知识。这一点能做到之后，通过网络做信息检索，寻找相关性较高的文本，整合转化为文本输出给用户的后续任务就比较简单了。

### 文本表示的发展历程
文本表示的目的是将人类语言的自然形式转化为计算机可以处理的形式，也就是将文本数据数字化，使计算机能够对文本进行有效的分析和处理。文本表示的需要做到语义信息的高度保留。  

<strong>VSM(传统向量空间模型)</strong>,直接将词映射到向量空间，通过查找整个词向量空间的位置，给0或1来确定出现了哪些词。缺点是向量极其稀疏难以计算，会造成维度灾难。  

<strong>Word2Vec </strong>通过通过在低维空间中优化上下文预测任务，使得对目标函数贡献较大的语义信息在训练过程中被梯度强化，而无关信息由于梯度接近于零而被自然抑制，从而实现任务驱动的有效信息压缩。比如原本经过one-hot编码的词向量维数为10000，经过一个Embedding层，这个层要求输出300维的向量，这里需要一个神经网络做上下文预测任务，上下文预测任务有两种，一是用上下文预测中心词（CBOW），而是中心词预测上下文，常用Skip-gram来训练，后者对低频词效果更好，泛化能力更强，所以一般采用后者。模型为了完成任务会把“上下文相似的词”映射到相近位置，比如vec(cat) ≈ vec(dog)，vec(king) - vec(man) ≈ vec(queen)。Skip-gram实际上是在隐式地分解一个经过平移的 PMI（点互信息）矩阵，其学习到的词向量内积近似等于词与上下文之间的统计共现信息，从而使得词向量能够有效编码语义关系。比如猫和牛奶一同出现的频率显著高于猫和手机。同时这种基于上下文预测任务输出词向量矩阵的方式也带来了一个很小的上下文窗口，但是对于长文本的理解能力就很差。另外这种方法无法解决一词多义的问题。也无法解决词序的问题，比如在这个矩阵中，人咬狗和狗咬人几乎是相同的。  

<strong>ELMo</strong>引入了BILSTM解决词序问题，因为双向的记忆会告诉模型词序，同时增大了上下文窗口。而一个词的不同意思通常依靠上下文决定，这一点也得到了优化，不过上下文仍然有限。  

<strong>Bert，GPT</strong>等基于transformer和自身注意力机制的模型的使得一个词可以查询语句中任何一个词的相关性，使得上下文几乎无限大。但实际上自我注意力的计算复杂度和语句长度的平方成正比，过长的语句目前还是难以计算。  

### Q&A
目前面临的困难其实从ChatGPT的使用过程中就可以看出来，表面问题一是上下文记忆长度还是不够长，第二是难以识别深层的隐喻，反讽。但其实这两点就人类来说，不是每个人都能完全意识到语句中的弦外之音，也不是每个人都能记住无限长的上下文。我们的大脑也在不断地做生成式摘要。而且人类之所以能意识到很多隐喻是因为我们的大脑这个模型的参数量足够大，除了文本的上下文我们还有事件的上下文，社会关系的上下文。所以现阶段模型之所以无法准确的意识到一些反讽，是因为提供的信息太少。很意外的是，类word2vec的模型对于中文中的“老冯”，“傻福”这种象形替换有很好的识别，因为它很快就能学习到“冯”和“飞”，“傻”和“福”一起出现就是恶意言论。深层的模型问题一是数据依赖问题，文本不正确的地方会被继承，二从模型的训练过程来看，所有基于上下文生成的语言模型其实没有理解到词语的本意，本质上还是在寻找向量空间中相近的词。

## Chapter 2 Transformer 架构 2026/04/17

### FNN,CNN与RNN  
从计算机视觉为起源发展起来的神经网络其核心架构有三种。

前馈神经网络（Feedforward Neural Network，FNN），即数据从输入层单向流动到输出层，无循环结构，各层之间通过<mark>全连接</mark>或特定方式传递信息，其中多层感知机（Multi-Layer Perceptron，MLP）是最常见的形式，每一层的神经元都和上下两层的每一个神经元完全连接。  

卷积神经网络（Convolutional Neural Network，CNN），使用卷积层和池化层进行了信息提取。  

循环神经网络（Recurrent Neural Network，RNN），能够使用历史信息作为输入、包含环和自重复的网络。

在transformer出现之前，LSTM是此领域最优异的模型，因为其时序建模的特点对于上下文的关系能理解的比较好，包括后续的带GRU的BILSTM，但是缺点前文已经提出了。完全由注意力机制构成的神经网络——Transformer，改变了这些缺点。

### 注意力机制
注意力机制最先源于计算机视觉领域，其核心思想为当我们关注一张图片，我们往往无需看清楚全部内容而仅将注意力集中在重点部分即可。  
注意力机制有三个核心变量：Query（查询值）、Key（键值）和 Value（真值）。例如，当我们有一篇新闻报道，我们想要找到这个报道的时间，那么，我们的 Query 可以是类似于“时间”、“日期”一类的向量（为了便于理解，此处使用文本来表示，但其实际是稠密的向量），Key 和 Value 会是整个文本。通过对 Query 和 Key 进行运算我们可以得到一个权重，这个权重其实反映了从 Query 出发，对文本每一个 token 应该分布的注意力相对大小。Query是一个标准的有关时间的向量，对于每一个文章里的字都进行相关性计算，最终通过这个相关性的值，来决定对整个文本注意力如何分配。  
​具体而言，注意力机制的特点是通过计算 Query 与Key的相关性为真值加权求和，从而拟合序列中每个词同其他词的相关关系。
接下来进行理论推导（以字典为例），假设有这样一个字典：  
{% highlight js linenos %}
{
    "apple":10,
    "banana":5,
    "chair":2
}
{% endhighlight %}  
当我们进行查询时，比如query为fruit，那么可以给出一个这样的权重  
{% highlight js linenos %}
{
    "apple":0.6,
    "banana":0.4,
    "chair":0
}
{% endhighlight %}
那么，我们最终查询到的值应该是：$v a l u e=0 . 6 * 1 0+0 . 4 * 5+0 * 2=8$  

给不同 Key 所赋予的不同权重，就是我们所说的注意力分数，也就是为了查询到 Query，我们应该赋予给每一个 Key 多少注意力。从直观上讲，我们可以认为 Key 与 Query 相关性越高，则其所应该赋予的注意力权重就越大。
transformer的注意力机制使用点积来计算相关性。点积的计算是方向性的，比如apple=[2,3],chair=[-1,-3]那么点积的值应该为-11，为非正数说明这两个词的相关性很小，且值大小能够说明相关性的程度大小。假设我们的 Query 为“fruit”，对应的词向量为 q；我们的 Key 对应的词向量为k=[v.apple,v.banana,v.chair],则我们可以计算 Query 和每一个键的相似程度：
$$
x=q K^{T}
$$  

其中假设q=[1,2]是标准的水果的一个向量，k转置是为了计算，最终的期望得到的x应该是类似于[3,3,-1]这说明k中的前两个键和fruit有相似性。权重还需要做一个归一化处理，这里用一个softmax层做：
$$
{\mathrm{s o f t m a x}} ( x )_{i}={\frac{e^{x i}} {\sum_{j} e^{x_{j}}}}
$$  

对于上面的x，过程应该就是：$e^x=[e^3,e^3,e^{-1}]≈[20.1,20.1,0.37]$再除他们的和得到权重。使用指数函数的优势在于使得值更加集中，避免极值的影响。我们再将得到的注意力分数和值向量做对应乘积即可。根据上述过程，我们就可以得到注意力机制计算的基本公式：
$$
\operatorname {a t t e n t i o n} (Q, K, V) = \operatorname {s o f t m a x} \left(q K ^ {T}\right) v
$$  

这个式子是权重乘全部键的真值的矩阵，即每个键的真值乘对应的权重再相加，得到的就是一个新的k，用这个k去对比，找之前所有k的点积最大那一个，应该是apple，那么说明apple是fruit。如果 Q 和 K 对应的维度$d_{k}$比较大，softmax 放缩时就非常容易受影响，使不同值之间的差异较大，从而影响梯度的稳定性。因此，我们要将 Q 和 K 乘积的结果做一个放缩:
$$
\operatorname {a t t e n t i o n} (Q, K, V) = \operatorname {s o f t m a x} \left(\frac {Q K ^ {T}}{\sqrt {d _ {k}}}\right) V
$$

#### 自注意力（Self-Attention）
普通的交叉注意力的Q和V来自两个不同的序列，所做的工作在于找到两个序列中token的对应关系。而自注意力的Q和V都来自一个序列，所做的工作在于使得本序列的每一个token都包含整个序列的信息。假设现在有一个序列X=[why u bulling me],对于其中的四个token生成词向量，此时的Q,K,V计算为：$Q=X W_{q} , \quad K=X W_{k} , \quad V=X W_{v}$ , 其中的$W_{q},W_{k},W_{v}$为可学习的矩阵，$W_{q},W_{k}$学习的是词和词之间的关系，$W_{v}$学习的是词的属性。

#### 掩码自注意力（Mask Self-Attention）
是指使用注意力掩码的自注意力机制。掩码的作用是遮蔽一些特定位置的 token，模型在学习的过程中，会忽略掉被遮蔽的 token。使用注意力掩码的核心动机是让模型只能使用历史信息进行预测而不能看到未来信息。语言模型是按顺序预测（类似 n-gram），但 Transformer 想要并行计算。
{% highlight js linenos %}
{
<BOS> 【MASK】【MASK】【MASK】【MASK】
<BOS>    I   【MASK】 【MASK】【MASK】
<BOS>    I     like  【MASK】【MASK】
<BOS>    I     like    you  【MASK】
<BOS>    I     like    you   </EOS>
}
{% endhighlight %}
实际计算中，mask为一个上三角为负无穷的矩阵，假设i love you 的attention分数，即进入softmax层之前的那个矩阵为：
$$
q K^{T}=\left[ \begin{matrix} {1} & {2} & {3} \\ {2} & {5} & {6} \\ {1} & {3} & {4} \\ \end{matrix} \right]
$$
那么就有：
$$
Q K^{T}+m a s k=\left[ \begin{matrix} {1} & {-\infty} & {-\infty} \\ {2} & {5} & {-\infty} \\ {1} & {3} & {4} \\ \end{matrix} \right]
$$
第一行为经过softmax层会输出[1,0,0],这告诉模型，这一行只能看i，而不能看后面的love 和 you。

#### 多头注意力（Multi-Head Attention）
注意力机制可以实现并行化与长期依赖关系拟合，但单头注意力只能在“同一个表示空间”里建模关系，表达能力受限，因此 Transformer 使用了多头注意力机制，即同时对一个语料进行多次注意力计算，每次注意力计算都能拟合不同的关系，将最后的多次结果拼接起来作为最后的输出，即可更全面深入地拟合语言信息。
首先我们还是输入一个x，对于每一个head都有：$Q_{i}=X W_{i}^{Q}  , \quad K_{i}=X W_{i}^{K} , \quad Q_{i}=X W_{i}^{Q}$,假设有8个头，原本的信息是512维的，那么经过这个线性变换，每个头就只看其中64维的信息，再将所有的head拼接，就有：
$$

最后乘这个$W^{O}$在代码表示中是通过一个线性层做一次融合起到去冗余，混合信息，调整维度的作用。

### Encoder-Decoder
在 Transformer 中，<mark>使用注意力机制的是其两个核心组件——Encoder（编码器）和 Decoder（解码器）。</mark>事实上，后续基于 Transformer 架构而来的预训练语言模型基本都是对 Encoder-Decoder 部分进行改进来构建新的模型架构，例如只使用 Encoder 的 BERT、只使用 Decoder 的 GPT 等。

#### Seq2Seq 模型
Seq2Seq，即序列到序列，是一种经典 NLP 任务。具体而言，是指模型输入的是一个自然语言序列 ，输出的是一个可能不等长的自然语言序列 。几乎所有的 NLP 任务都可以视为 Seq2Seq 任务。例如文本分类任务，可以视为输出长度为 1 的目标序列；词性标注任务，可以视为输出与输入序列等长的目标序列；机器翻译任务即是一个经典的 Seq2Seq 任务，例如，我们的输入可能是“今天天气真好”，输出是“Today is a good day.”Transformer 是一个经典的 Seq2Seq 模型，即模型的输入为文本序列，输出为另一个文本序列。事实上，Transformer 一开始正是应用在机器翻译任务上的。  

对于 Seq2Seq 任务，一般的思路是对自然语言序列进行编码再解码。所谓编码，就是将输入的自然语言序列通过隐藏层编码成能够表征语义的向量（或矩阵），可以简单理解为更复杂的词向量表示。而解码，就是对输入的自然语言序列编码得到的向量或矩阵通过隐藏层输出，再解码成对应的自然语言目标序列。通过编码再解码，就可以实现 Seq2Seq 任务。  
 
Transformer 由 Encoder 和 Decoder 组成，每一个 Encoder（Decoder）又由 6个 Encoder（Decoder）Layer 组成。输入源序列会进入 Encoder 进行编码，到 Encoder Layer 的最顶层再将编码结果输出给 Decoder Layer 的每一层，通过 Decoder 解码后就可以得到输出目标序列了。  

#### transformer中的前馈神经网络

{% highlight js linenos %}
{  
class MLP(nn.Module):

    def __init__(self, dim: int, hidden_dim: int, dropout: float):
        super().__init__()
        # 定义第一层线性变换，从输入维度到隐藏维度
        self.w1 = nn.Linear(dim, hidden_dim, bias=False)
        # 定义第二层线性变换，从隐藏维度到输入维度
        self.w2 = nn.Linear(hidden_dim, dim, bias=False)
        # 定义dropout层，用于防止过拟合
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        # 前向传播函数
        # 首先，输入x通过第一层线性变换和RELU激活函数
        # 最后，通过第二层线性变换和dropout层
        return self.dropout(self.w2(F.relu(self.w1(x)))) 
}
{% endhighlight %}  

这里的结构为：$h = \mathrm{ReLU}(Wx + b)$,ReLU函数的本质是$\boldsymbol{f} ( x )=\operatorname*{max} ( 0 , x )$,这是一个简单的激活函数，意思是大于某个值的数值就保留，通过这种切割再叠加线性层，可以逼近一些复杂的函数。

#### 归一化（Normalization）
神经网络主流的归一化一般有两种，批归一化（Batch Norm）和层归一化（Layer Norm）。  

由于深度神经网络中每一层的输入都是上一层的输出，因此多层传递下，对网络中较高的层，之前的所有神经层的参数变化会导致其输入的分布发生较大的改变。而且这种变化是指数级的，对应输出较大的层容易梯度爆炸，反之则梯度消失。需要通过这种操作来将输出控制在一个范围内。

BN：对于一个batch size中的所有样本做归一化，让不同样本之间更加一致。  
LN：对于每一个样本内的，比如一个四维数据，对四个数据做归一化，让样本内部更加平均。  
比如现在输入是一个五维向量，batch size=64，即一个5*64的矩阵，BN对于第一列的64个数据做归一化，LN对每一行的5个数据做归一化。BN的缺陷在于如果训练和推理的维数不一样，那么会导致后面的维数无法标准化。所以在深度学习中更加常用LN。

在整个模型中有Pre-Norm，Post-Norm两种放置归一化的位置，Post-Norm：先变换再归一化$y = \mathrm{LayerNorm}(x + F(x))$，Pre-Norm：先归一化再变换 $y = x +\mathrm{LayerNorm}( F(x))$。最关键的区别在于后者对x求偏导会有一个1的项，在模型中这表明有一条笔直的梯度通道可以快速向底层传递高层的信息。所以现在更加先进的大模型中都使用pre-norm。而标准的layernorm会做放缩归一化和均值中心化，即使方差为1，均值为0。因为去均值会导致梯度不稳定，现普遍使用的RMSNorm只做方差放缩。

我们可以简单地实现一个LN层：  
{% highlight js linenos %}
{
class LayerNorm(nn.Module):

    def __init__(self, features, eps=1e-6):
        super().__init__()
        # 线性矩阵做映射
        self.a_2 = nn.Parameter(torch.ones(features))
        self.b_2 = nn.Parameter(torch.zeros(features))
        self.eps = eps
	
    def forward(self, x):
        # 在统计每个样本所有维度的值，求均值和方差
        mean = x.mean(-1, keepdim=True) # mean: [bsz, max_len, 1]
        std = x.std(-1, keepdim=True) # std: [bsz, max_len, 1]
        # 注意这里也在最后一个维度发生了广播
        return self.a_2 * (x - mean) / (std + self.eps) + self.b_2
}
{% endhighlight %} 

#### 残差连接(Residual Connection)
由于 Transformer 模型结构较复杂、层数较深，​为了避免模型退化，Transformer 采用了残差连接的思想来连接每一个子层。残差连接，即当前层的输入为x1，那么应该输出y1=x1+F1（x1），这个输出到下一层x2=y1，下一层输出y2=x2+F2(X2),如此循环。残差连接允许最底层信息直接传到最高层，让高层专注于残差的学习。残差就像变化，模型学习的并不是前面所有的数据，而是上一次的学习成果和变化了什么。就像一个无法直接得出答案的证明题，残差就是其中一个个细小的步骤。

#### Encoder
Encoder 由 N 个 Encoder Layer 组成，每一个 Encoder Layer 包括一个注意力层和一个前馈神经网络。因此，我们可以首先实现一个 Encoder Layer：  
{% highlight js linenos %}
{
class EncoderLayer(nn.Module):

    def __init__(self, args):
        super().__init__()
        # 一个 Layer 中有两个 LayerNorm，分别在 Attention 之前和 MLP 之前
        self.attention_norm = LayerNorm(args.n_embd)
        # Encoder 不需要掩码，传入 is_causal=False
        self.attention = MultiHeadAttention(args, is_causal=False)
        self.fnn_norm = LayerNorm(args.n_embd)
        self.feed_forward = MLP(args.dim, args.dim, args.dropout)

    def forward(self, x):
        # Layer Norm
        norm_x = self.attention_norm(x)
        # 自注意力
        h = x + self.attention.forward(norm_x, norm_x, norm_x)
        # 经过前馈神经网络
        out = h + self.feed_forward.forward(self.fnn_norm(h))
        return out
}
{% endhighlight %}   
然后我们搭建一个 Encoder，由 N 个 Encoder Layer 组成，在最后会加入一个 Layer Norm 实现规范化：  
{% highlight js linenos %}
{  
class Encoder(nn.Module):
    '''Encoder 块'''
    def __init__(self, args):
        super(Encoder, self).__init__() 
        # 一个 Encoder 由 N 个 Encoder Layer 组成
        self.layers = nn.ModuleList([EncoderLayer(args) for _ in range(args.n_layer)])
        self.norm = LayerNorm(args.n_embd)

    def forward(self, x):
        "分别通过 N 层 Encoder Layer"
        for layer in self.layers:
            x = layer(x)
        return self.norm(x)
}
{% endhighlight %} 

#### Decoder
和 Encoder 不同的是，Decoder 由<mark>两个</mark>注意力层和一个前馈神经网络组成。第一个注意力层是一个掩码自注意力层，即使用 Mask 的注意力计算，保证每一个 token 只能使用该 token 之前的注意力分数；第二个注意力层是一个多头注意力层，该层将使用第一个注意力层的输出作为 query，使用 Encoder 的输出作为 key 和 value，来计算注意力分数。意义在于前者是学习，后者是对齐输出，因为qkv来自不同的模块。最后，再经过前馈神经网络：
{% highlight js linenos %}
{ 
class DecoderLayer(nn.Module):
  '''解码层'''
    def __init__(self, args):
        super().__init__()
        # 一个 Layer 中有三个 LayerNorm，分别在 Mask Attention 之前、Self Attention 之前和 MLP 之前
        self.attention_norm_1 = LayerNorm(args.n_embd)
        # Decoder 的第一个部分是 Mask Attention，传入 is_causal=True
        self.mask_attention = MultiHeadAttention(args, is_causal=True)
        self.attention_norm_2 = LayerNorm(args.n_embd)
        # Decoder 的第二个部分是 类似于 Encoder 的 Attention，传入 is_causal=False
        self.attention = MultiHeadAttention(args, is_causal=False)
        self.ffn_norm = LayerNorm(args.n_embd)
        # 第三个部分是 MLP
        self.feed_forward = MLP(args.dim, args.dim, args.dropout)

    def forward(self, x, enc_out):
        # Layer Norm
        norm_x = self.attention_norm_1(x)
        # 掩码自注意力
        x = x + self.mask_attention.forward(norm_x, norm_x, norm_x)
        # 多头注意力
        norm_x = self.attention_norm_2(x)
        h = x + self.attention.forward(norm_x, enc_out, enc_out)
        # 经过前馈神经网络
        out = h + self.feed_forward.forward(self.ffn_norm(h))
        return out
}
{% endhighlight %}

### 搭建一个transformer

#### Embedding 层
这一层的作用为将自然语言的输入转化为机器可以处理的向量。在输入神经网络之前，我们往往会先让自然语言输入通过分词器 tokenizer，分词器的作用是把自然语言输入切分成 token 并转化成一个固定的 index。对于每个token开始训练n维（n=embedding_dim）词向量的值。

#### 位置编码
为使用序列顺序信息，保留序列中的相对位置信息，Transformer 采用了正余弦函数来进行位置编码（绝对位置编码Sinusoidal）。该方式通过“多频率正余弦组成的高维向量结构”，让不同位置在向量空间中几乎唯一并且因为设计的原因，可以通过和差化积计算出相对距离。但是通过公式计算出的值属于静态值，即表示的位置的绝对位置，但是现代LLM中更需要相对位置,在上述方法中$x = token\_embedding + PE(pos)$，位置信息只是被包含了，不是attention的一部分。  
RoPE 的核心是让 Q 和 K 自带位置旋转。直接在向量前加一个旋转矩阵，通过角度来决定位置。由于这种角度的性质，天然更适合相对位置的计算。但是当序列太长的时候，角度积累会变得很大，这样即使w/10000也超过一个正弦函数的周期了。

### Q&A
Q:Transformer 为什么会有三种结构？它们各自“适合解决什么任务”？  
A:Encoder-only（理解型模型）,代表模型bert，输入完整的句子，输入序列内的信息。功能为理解输入序列内的信息，适合文本分类，情感分析，实体识别的工作。这类工作不需要生成，只需要理解，所以不需要解码器。优势在于理解能力和上下文理解完整。  
Decoder-only（生成型模型），代表模型GPT，输入的是前文，输出下一个token。通过单向注意力，只能看历史的信息。适合生成文章，代码，对话。  
Encoder–Decoder（翻译/转换型），代表模型为T5,bart。基于前两种模型，可以知道，这类模型需要先理解序列内容，再生成一个对应的序列。比如题目——>答案。  
很反直觉的是GPT居然是Decoder-only而不是Encoder–Decoder，明明在使用中我们都是给GPT输入一个需求，再让他生成解决方案，这完全是Encoder–Decoder的模式。但是实际上，GPT做了一件事，就是把所有的问题转化成文本生成任务，比如：原任务：情感分类：正面 / 负面，改写成：This movie is great. The sentiment is:模型输出：positive。实际上“预测下一个词”迫使模型学习“隐含的因果结构和世界规律”，而几乎所有的任务都能够转化为这种形式。所以模型不是真的理解了情感，逻辑，知识，而是在人类广阔的文本中，巨量的数据集中学会了文本分布这一件事。只是参数越大的模型，它们学习到的文本背后的逻辑更多，显得更加智能。  
Q:多头注意力相比单头有什么优势？  
A：这个在前文的笔记中已经显式地表达了，单头注意力只能在“同一个表示空间”里建模关系，表达能力受限，多头注意力机制同时对一个语料进行多次注意力计算，每次注意力计算都能拟合不同的关系，将最后的多次结果拼接起来作为最后的输出，即可更全面深入地拟合语言信息。更详细的解释，比如一个语句:"今天是星期四，我要吃KFC",第一个头学习语句逻辑，第二个头学习语义，第三个头学实体等等。更复杂的语句往往包含多种逻辑，而一个头一个向量空间中无法建模多个关系。  
Q: LLaMA2 的结构分为那几部分，是否属于解码器only中的某一类，优势劣势是什么？未来发展趋势是什么？  
A：LLaMA2 属于Decoder-only Transformer，结构为：Token Embedding——>Decoder(自注意力，RoPE位置编码，causal mask,FNNSwiGLU激活,残差链接，RMSNorm)——>Linear——>softmax。缺点在于RePE编码，上面叙述了和这个缺陷带来的一系列缺陷。发展趋势我们可以从LLaMA后面的模型来看，LLaMA3改用RoPE scaling，使用了更加标准的归一化和初始化策略。这么看来，位置编码的需要革新，因为这是一个限制上下文长度的关键因素。第二就是attention的算法，目前的时间复杂度为$O \left(n^{2}\right)$,限制了训练规模和革新速度，比如可以使用稀疏注意力，即更少量地关注全局，mamba使用SSM代替了attention，它的时间复杂度为$O \left(n\right)$，类似于一个固定卷积核的长卷积，一次性处理所有token。第三就是编码器和解码器的内置神经网络的优化，FNN还是比较受限的。  
Q:如何从零训练一个LLM？  
A：任何机器学习相关的任务中，数据集质量绝对是影响模型性能最关键的一项。所以先收集足够的语料，并且做清洗，当然也有C4这样的开源数据集，但主要是英文，如果要训练原生中文的LLM目前应该没有很好的数据集。第二是做分词，目前来看，token越小，同时拼接层的维数越大，效果越好。第三就是构建模型，LLM基本都是Decoder-only，架构很成熟主要是小细节的调整比如decoder的层数，注意力机制的选择，激活函数，位置编码函数。第四训练阶段，选择合适的训练任务（MLM+SOP比较适合上下文生成），损失函数，训练框架。第五是微调，选择适合下游任务的精细人工标注的语料库。最后是部署。  
Q:subword tokenizer 的核心设计思想是什么？请举例说明
A: 核心在于把词分到一个比较合适的细粒度,达到节约此表，增加泛化未登录词的能力。比如unhappiness会被分为un-happi-ness，traditional分为tradi-tion-al，这种把词分为前缀-词根-后缀的方式对于未登录词有较强的泛化能力，这时候出现一个n+er形式的词大概率就是这个名词的从业者，比较符合人类的语言学习习惯。但是分的不能太细了，会失去最基本的表意能力。另外一个就是借助这种分词节约词表的空间，比如teacher，teaching，teachable，在词表中可能只会保留一个teach，还有大部分形容词的比较级和最高级，动词的不同时态，各种ment，tion后缀等都属于这种方式的适用领域。

### Encoder-only PLM
#### BERT
是由 Google 团队在 2018年发布的预训练语言模型,承袭Transformer 架构，语言模型预训练+下游任务微调范式。BERT 是针对于 NLU 任务打造的预训练模型，所以在模型的最顶层加入了一个分类头 prediction_heads，用于将多维度的隐藏状态通过线性层转换到分类维度，输出的维数取决于是几分类任务。模型整体既是由 Embedding、Encoder 加上 prediction_heads 组成。  

输入的文本序列会首先通过 tokenizer（分词器） 转化成 input_ids，然后进入 Embedding 层转化为特定维度的 hidden_states，再经过 Encoder 块。Encoder 块中是堆叠起来的 N 层 Encoder Layer。通过Encoder 编码之后的最顶层 hidden_states 最后经过 prediction_heads 就得到了最后的类别概率，经过 Softmax 计算就可以计算出模型预测的类别。prediction_heads 的内部为linear->激活函数->linear。  

BERT 所使用的激活函数是 GELU 函数，其原始形态需要正态分布CDF,常用这个公式逼近：
$$
G E L U (x) ≈ 0. 5 x \left(1 + t a n h \left(\sqrt {\frac {2}{\pi}}\right) \left(x + 0. 0 4 4 7 1 5 x ^ {3}\right)\right)
$$
GELU 的核心思路为将随机正则的思想引入激活函数，通过输入自身的概率分布，来决定抛弃还是保留自身的神经元。GELU是由RELU发展来的，RELU前文已经分析过，是一个简单的通过正负抛弃神经元的方式，容易造成神经元死亡，这样梯度就一直是0，而GELU更加平滑，对于负神经元只是缩小而不是直接抛弃。  

BERT 更大的创新点在于其提出的两个新的预训练任务上——MLM 和 NSP（Next Sentence Prediction，下一句预测），前者掩码语言模型在前文已经介绍过，在这里多了一个优势，就是使得所有未被人工标注的文本都可以作为数据集，这大幅提高了参数量。NSP 是针对句级的 NLU 任务，例如问答匹配、自然语言推理等。问答匹配是指，输入一个问题和若干个回答，要求模型找出问题的真正回答；自然语言推理是指，输入一个前提和一个推理，判断推理是否是符合前提的或判断一个句对的两个句子是否是连续的上下文。这样的任务都需要模型在句级去拟合关系，判断两个句子之间的关系，而不仅是 MLM 在 token 级拟合的语义关系。

训练-微调的思想，即在海量无监督语料上进行预训练来获得通用的文本理解与生成能力，再在对应的下游任务上进行微调。其优势在于可以利用原模型通过海量的预训练语料来让模型拟合的潜在语义与底层知识，这使得人们更愿意使用长时间，大规模的预训练，再进行迁移学习。微调其实和训练时更新模型参数的策略一致，只不过在特定的任务、更少的训练数据、更小的 batch_size 上进行训练，更新参数的幅度更小。

#### RoBERTa
RoBERTa是基于BERT发展的，其几个改变为：  
1.通过消融实验证明了NSP任务不能提高模型性能，因此去掉了。对MLM任务更新，将mask放在训练阶段，原本是先mask再训练，这样每个epoch的mask是一样的，但是更新后每个epoch都不一样。在实验中，动态遮蔽仅有很微弱的优势优于静态遮蔽，但由于动态遮蔽更高效、易于实现，后续 MLM 任务基本都使用了动态遮蔽。  
2.更大规模的预训练数据和预训练步长，十倍于BERT的数据，步长由256变为512。  
3.BERT 使用的 WordPiece 算法不同，RoBERTa使用 BPE作为Tokenizer的编码策略。这种方式将词分得更小，对“Hello World”这句话，可能会切分为“Hel，lo，Wor，ld”四个子词对。   
RoBERTa的成功也证明了更大的预训练数据、更大的预训练步长的重要意义，这也是LLM诞生的基础之一。  

#### ALBERT
与RoBERTa不同，ALBERT是一种模型参数更小的BERT。其几个改变为：  
1.ALBERT 对Embedding层的参数矩阵进行了分解，让Embedding层的输出维度和隐藏层维度解绑，也就是在 Embedding层的后面加入一个线性矩阵进行维度变换。  
2.让各个 Encoder 层共享模型参数，来减少模型的参数量,同时增大隐藏层的维数。
3.ALBERT 改进NSP，增加其难度，提出了SOP。在传统的 NSP 任务中，正例是由两个连续句子组成的句对，而负例则是从任意两篇文档中抽取出的句对，模型可以较容易地判断正负例，并不能很好地学习深度语义。而 SOP 任务提出的改进是，正例同样由两个连续句子组成，但负例是将这两个的顺序反过来。

### Encoder-Decoder PLM
#### T5
T5（Text-To-Text Transfer Transformer）是由 Google 提出的一种预训练语言模型，通过将所有 NLP 任务统一表示为文本到文本的转换问题，大大简化了模型设计和任务处理。T5 基于 Transformer 架构，包含编码器和解码器两个部分，使用自注意力机制和多头注意力捕捉全局依赖关系，利用相对位置编码处理长序列中的位置信息，并在每层中包含前馈神经网络进一步处理特征。其结构几乎和最初始的Transformer一模一样。  
特殊的地方在于，Decoder 中还包含了 Encoder-Decoder Attention 结构，用于捕捉输入和输出序列之间的依赖关系。采用了RMSNorm，前文介绍了，是不做均值为0的LayerNorm。预训练任务是MLM。  
T5模型提出的所有的NLP任务都可以统一为文本到文本的任务的思想，为GPT将所有问题都转化为上下文生成问题提供了前鉴。

### Decoder-Only PLM
目前所有的LLM基本都是Decoder-Only模型（RWKV、Mamba 等非Transformer架构除外）。而引发LLM热潮的 ChatGPT，正是Decoder-Only系列的代表模型GPT系列模型的大成之作。因此仔细学习此类架构是了解LLM的必由之路。
#### GPT
![example](/image/GPT模型结构.png)  
模型框架上，在解码器层的内部，相较于 Transformer 原始 Decoder 层的双注意力层设计，GPT 的 Decoder 层反而更像 Encoder 层一点。由于不再有 Encoder 的编码输入，Decoder 层仅保留了一个带掩码的自注意力层，这里的核心在于把“输入 + 输出”拼成一个序列，输入也在上下文里，所以不需要交叉注意力来对齐。并且将 LayerNorm 层从 Transformer 的注意力层之后提到了注意力层之前。GPT 的 MLP 层没有选择线性矩阵来进行特征提取，而是选择了两个一维卷积核来提取，不过，从效果上说这两者是没有太大区别的。MLP（多层感知机）是FNN的一种，区别在于使用了GELU，而不是基础的RELU。  
预测任务使用了因果语言模型，Causal Language Model，下简称 CLM。相较于NSP和SOP这个问题更加接近这个命名的本质，NSP虽然叫下一句预测，但实际上做的是二分类任务，只需要回答两个句子是不是上下文的关系。而CLM才是真正的下一个token生成。CLM的优势在于符合人类的书写习惯，并且也保留了可以使用海量的自然语言语料进行大规模的预训练的特征。  
GPT的模型迭代主要体现在参数增大上，但细节上还有：  
GPT-2将 Post-Norm 改为了 Pre-Norm。GPT-2 的另一个重大突破是以 zero-shot（零样本学习）为主要目标，也就是不对模型进行微调，直接要求模型解决任务。例如，在传统的预训练-微调范式中，我们要解决一个问题，一般需要收集几百上千的训练样本，在这些训练样本上微调预训练语言模型来实现该问题的解决。而 zero-shot 则强调不使用任何训练样本，直接通过向预训练语言模型描述问题来去解决该问题。zero-shot 的思路自然是比预训练-微调范式更进一步、更高效的自然语言范式，但是在 GPT-2 的时代，模型能力还不足够支撑较好的 zero-shot 效果，在大模型时代，zero-shot 及其延伸出的 few-shot（少样本学习）才开始逐渐成为主流。零样本学习其实就是类似于我们和大模型聊天的样子，比如我们规定1=4，2=8,3=12，问模型4=？它可以推理出16,但是要是直接问4=？，模型肯定会回答4。这虽然是一个很简单的例子，但是说明了在具备一定涌现能力的模型上零样本学习的可行性。  
GPT-3使用了稀疏注意力机制，前文介绍过，这种注意力不再计算每个token和本token的关系，而是只计算一部分。GPT-3的参数量是175B而2为1.5B，足足116倍，其巨大的体量带来了涌现能力的凸显。还提出了少样本学习方法也被称为上下文学习（In-context Learning），其实上面零样本学习的例子更像少样本的，少样本不同之处在于给予模型少了的示例。这种叫人类反馈强化学习的方式，无需进行高成本的额外训练或微调，而可以通过少数示例或是调整自然语言指令，来处理绝大部分任务，从而大大节省了算力和数据成本。
#### LLaMA
LLaMA模型也是Decoder-Only架构。整体结构和GPT也很相似：  
将输入文本通过tokenizer进行编码，转化为一系列的input_ids。这些input_ids是模型能够理解和处理的数据格式。接下来，这些input_ids会经过embedding层的转换，这里每个input_id会被映射到一个高维空间中的向量，即词向量。同时，输入文本的位置信息也会通过positional embedding层被编码，以确保模型能够理解词序上下文信息。  
这样，input_ids经过embedding层和positional embedding层的结合，形成了hidden_states。hidden_states包含了输入文本的语义和位置信息，是模型进行后续处理的基础，hidden_states随后被输入到模型的decoder层。  
在decoder层中，hidden_states会经历一系列的处理，这些处理由多个decoder block组成。每个decoder block都是模型的核心组成部分，它们负责对hidden_states进行深入的分析和转换。在每个decoder block内部，首先是一个masked self-attention层。在这个层中，模型会分别计算query、key和value这三个向量。这些向量是通过hidden_states线性变换得到的，它们是计算注意力权重的基础。然后使用softmax函数计算attention score，这个分数反映了不同位置之间的关联强度。通过attention score，模型能够确定在生成当前词时，应该给予不同位置的hidden_states多大的关注。然后，模型将value向量与attention score相乘，得到加权后的value，这就是attention的结果。  
在完成masked self-attention层之后，hidden_states会进入MLP层。在这个多层感知机层中，模型通过两个全连接层对hidden_states进行进一步的特征提取。第一个全连接层将hidden_states映射到一个中间维度，然后通过激活函数进行非线性变换，增加模型的非线性能力。第二个全连接层则将特征再次映射回原始的hidden_states维度。  
最后，经过多个decoder block的处理，hidden_states会通过一个线性层进行最终的映射，这个线性层的输出维度与词表维度相同。这样，模型就可以根据hidden_states生成目标序列的概率分布，进而通过采样或贪婪解码等方法，生成最终的输出序列。这一过程体现了LLaMA模型强大的序列生成能力。  
LLaMA-2 系列引入了分组查询注意力机制（Grouped-Query Attention, GQA）。在标准多头注意力（MHA）里每个 head 都有独立的 Q,K,V，计算量和显存（尤其 KV cache）都很大。MQA（Multi-Query Attention）所有的Q head
共享同一组 K、V但是表达能力下降了。GQA是这两种的一个折中方案：把多个 Q head 分组，每组共享一组 K、V。  还使用了更加非线性的SwiGLU作为激活函数。  
#### GLM
是一个中文语料训练的GPT。细微差异在于使用 Post Norm 而非 Pre Norm。使用单个线性层实现最终 token 的预测，而不是使用 MLP。激活函数从 ReLU 换成了 GeLUs。  
GLM 的核心创新点主要在于其提出的 GLM（General Language Model，通用语言模型）任务。通过优化一个自回归空白填充任务来实现 MLM 与 CLM 思想的结合。其核心思想是，对于一个输入序列，会类似于 MLM 一样进行随机的掩码，但遮蔽的不是和 MLM 一样的单个 token，而是每次遮蔽一连串 token；模型在学习时，既需要使用遮蔽部分的上下文预测遮蔽部分，在遮蔽部分内部又需要以 CLM 的方式完成被遮蔽的 tokens 的预测。
### Q&A
Q：为什么现在大模型微调很少用全参数微调，而是普遍用 LoRA 等高效微调（PEFT）方法？  
A：计算存储困难，另外全量训练相当于重新训练了，然而此时的数据集通常很小，很容易导致性能倒退。LoRA本质是在原本的权重后加两个低秩的小矩阵:$W^{\prime}=W+BA$,BA就是这两个小矩阵。  
Q:文本如何与图像对齐，对齐之后获得的的是什么，三个模态比如文本，图像，语音，甚至更多个模态如何处理?  
A：核心在于将不同模态的语义映射到同一个向量空间，最基础的方法是使用对比学习，正样本：(狗的图片, “a dog”)负样本：(狗的图片, “a car”)。对齐之后得到共享语义空间，一个向量空间里不同的同一语义靠得很近。Cross-Attention的融合方法做了多模态拼接，使得不是靠得很近，是完全重合，只是选择输出的模态不一样。GPT-4o统一建模，所有模态token化，丢进同一个Transformer，本质是把“图像、语音”都当作“语言”。统一的方式理论上可以兼容无限多的模态。
Q:LLM Agent的记忆、规划、工具调用三组件分别干什么？
A:memory储存上下文，planning使得LLM像人类一样思考，可以多步推理，连续解决问题，tool使得agent可以访问外部世界，比如网络检索，直接在编译器里执行代码，操作你的系统帮你发邮件，调用其他的模型，这三大组件补足了LLM除文本生成外的缺陷。
Q:为什么AI会出现幻觉，最近刚出的ChatGPT 的version和DeepSeek的version在什么层面进行了提升（技术&能力）？
A:因为LLM的能力是掌握文本分布的概率，它没有判断正误的能力。并且“不知道”这三个字的分布概率，对于任何一个文本，都不可能距离很近，不然模型全回答不知道了。再加上RM的鼓励机制，模型更愿意编造一个回答。RAG检索增强会从外部数据库查事实，不依靠模型数据。tool调用也差不多是这个原理。
